**Problem:** Pull request reviews were slow, inconsistent, and missed recurring code quality issues across multi-language codebases.

**Aim:** Automate the detection of bugs, code smells, and style violations before a single line reaches main.

**Solution:** Built an NLP-powered static analysis pipeline supporting 6 languages, integrated directly into CI/CD to deliver inline feedback on every commit — cutting average PR review time by 48%.

**Problem:** Drivers in dense urban lots wasted time circling to find open spots with no real-time visibility into availability.

**Aim:** Build a full-stack IoT platform that maps live slot occupancy and surfaces it to users instantly.

**Solution:** Architected an ESP32 sensor network with IR/PIR occupancy detection feeding a live web dashboard, plus LDR-based night lighting — reducing average search time by 60%.

[🔗 View Project](https://github.com/SawwmyaP/ParkerOS)
